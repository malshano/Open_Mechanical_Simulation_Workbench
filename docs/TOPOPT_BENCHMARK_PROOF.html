4. Limits found

At most 60 000 unknowns without pypardiso (the 300 x 100 slab has 182 000); at most 40 million filter links (a radius of 8 on 32 x 16 x 16 needs 135 million); radius floor of 3 element sizes, so the published 3D radius of sqrt(3) cells cannot be reproduced on any mesh.

5. Reproduce

python -m simwb.topopt.literature --full reruns the 2D table. python -m pytest tests/test_topopt_literature.py runs the 8 quick checks. The 3D reference run is literature.top3d(48, ft=3, bc="N", maxit=100), about 45 minutes and 2.3 GB.

Sources: Andreassen, Clausen, Schevenels, Lazarov, Sigmund, Struct Multidisc Optim 43 (2011), Figs. 3 and 8. Ferrari and Sigmund, arXiv 2005.05436, Fig. 8 and appendix C.
